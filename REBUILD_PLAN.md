# Kovick rebuild

The Alpha is being rebuilt around an independent architecture inspired by the observable behavior of Android keymapper applications.

Goals:
- real per-game profiles
- overlay editor
- physical keyboard mapping to screen coordinates
- mouse/aim input pipeline using Android accessibility motion events where supported
- foreground service lifecycle
- activation/deactivation without closing the game
- persistent sensitivity and mappings

Reference apps are used only for behavior and architecture. No proprietary source code or assets are copied.
